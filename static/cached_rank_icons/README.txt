Optional rank emblem backups. CommunityDragon is preferred; local files are used if it is unavailable.

For example, store Rank=Bronze.png, Rank=Master.png, and Rank=Grandmaster.png here.
Supported ranks: Iron, Bronze, Silver, Gold, Platinum, Emerald, Diamond, Master, Grandmaster, Challenger.

Do not delete cached bronze.png, master.png, etc. if already downloaded.
